# team-pelmeni
# Сервис бронирования переговорных комнат

## 1. О проекте

**Сервис бронирования переговорных комнат** — система для управления бронированием комнат внутри организации. Она позволяет сотрудникам находить свободные помещения, создавать бронирования на определённое время, подтверждать, отменять и переносить их, а также получать уведомления о предстоящих бронированиях.

Основная цель проекта — упростить процесс организации встреч и предотвратить ситуации, когда несколько сотрудников одновременно занимают одну и ту же комнату.

## 2. Какую проблему решает сервис

В организациях с несколькими переговорными комнатами часто возникают проблемы с распределением помещений:

- Сотрудники не знают, какие комнаты свободны в определённое время.
- Несколько человек могут попытаться занять одну комнату на один и тот же интервал.
- Возникают сложности с отменой и переносом запланированных встреч.
- Отсутствует единое место для просмотра собственных бронирований.

Наш сервис решает эти проблемы за счёт централизованного управления бронированиями и автоматической проверки доступности комнат.

## 3. Целевая аудитория

Основные пользователи системы:

- **Сотрудники организации** — создают, подтверждают, отменяют и переносят бронирования, а также просматривают список своих встреч.
- **Организации и компании** — используют сервис для упорядочивания процесса бронирования переговорных комнат.

## 4. Основные возможности системы

Сервис предоставляет следующие функции:

1. **Просмотр доступности комнат** — поиск свободных помещений на указанный временной интервал.
2. **Создание бронирования** — выбор комнаты, времени и темы встречи.
3. **Подтверждение бронирования** — подтверждение созданной заявки сотрудником.
4. **Автоматическая отмена неподтверждённых бронирований** — если сотрудник не подтвердил бронь до начала встречи, она автоматически отменяется.
5. **Отмена бронирования** — возможность освободить комнату до начала встречи.
6. **Перенос бронирования** — изменение времени встречи и (или) выбранной комнаты.
7. **Просмотр своих бронирований** — получение списка предстоящих и прошедших встреч.
8. **Высылает напоминания** - автоматическое направление уведомлений о предстоящем бронировании.

## 5. Основные правила работы

При работе с бронированиями система соблюдает следующие правила:

- Нельзя забронировать комнату на время, которое уже прошло.
- Нельзя создать две брони одной комнаты на пересекающиеся временные интервалы.
- Перед созданием бронирования система проверяет доступность и статус комнаты.
- Созданное бронирование первоначально получает статус `PENDING_CONFIRMATION`.
- После подтверждения сотрудником бронирование переходит в статус `CONFIRMED`.
- Неподтверждённое бронирование автоматически отменяется при наступлении времени начала встречи.
- Отменить подтверждённое бронирование можно только до начала встречи.
- После наступления времени окончания встречи бронирование получает статус `COMPLETED`.

## 6. Жизненный цикл бронирования

Каждое бронирование проходит определённые состояния:

| Статус | Описание |
|---|---|
| `PENDING_CONFIRMATION` | Бронирование создано и ожидает подтверждения сотрудником. |
| `CONFIRMED` | Бронирование подтверждено, комната закреплена за сотрудником. |
| `CANCELLED` | Бронирование отменено. |
| `COMPLETED` | Встреча завершена. |

Основные переходы между состояниями:

- `PENDING_CONFIRMATION` → `CONFIRMED` — сотрудник подтвердил бронирование.
- `PENDING_CONFIRMATION` → `CANCELLED` — сотрудник отменил бронирование или наступило время начала встречи без подтверждения.
- `CONFIRMED` → `CANCELLED` — сотрудник отменил бронирование до начала встречи.
- `CONFIRMED` → `COMPLETED` — наступило время окончания встречи.

## 7. Границы системы

### Что входит в систему

- Управление бронированиями переговорных комнат.
- Проверка доступности комнат.
- Проверка пересечения временных интервалов.
- Создание и подтверждение бронирований.
- Отмена и перенос бронирований.
- Просмотр списка собственных бронирований.
- Автоматическое изменение статусов бронирований в зависимости от времени.
- Фоновые задания: подтверждение брони (доставка уведомления).
- Уведомления: запись в БД и доставка через SMS-провайдера (адаптер SmsNotifier).

### Что не входит в систему

- Управление штатным расписанием сотрудников и кадровым учётом.
- Управление физическим доступом в переговорные комнаты и электронными замками.
- Управление оборудованием и техническим обслуживанием помещений.
- Организация видеоконференций и проведение онлайн-встреч.
- Управление рабочими задачами сотрудников, не связанными с бронированием комнат.
- Мобильное приложение, multi-tenancy.
